# 👤 Personal Portfolio Project

Welcome to my personal portfolio! This is a dedicated project where I showcase my skills, projects, and learning journey in Web Development.

## 🚀 Current Status: HTML & CSS Phase
Right now, this portfolio is built using pure **HTML5** and **CSS3**. 
- **Structure:** Clean and semantic HTML.
- **Styling:** Custom CSS with a focus on layout (Flexbox/Grid).
- **Responsiveness:** Making sure it looks good on different screens.

## 🛠️ Features Included
- **About Me Section:** Information about my learning journey.
- **Projects Showcase:** Links and details of my web tasks.
- **Contact Info:** Ways to reach out to me.
- **Responsive Navigation:** A clean header for easy browsing.

## 🔮 Future Enhancements (JavaScript Integration)
I plan to upgrade this portfolio soon by adding **JavaScript** for:
- **Interactive Elements:** Smooth scrolling and hover effects.
- **Dynamic Projects:** Using JS to load project details dynamically.
- **Dark/Light Mode:** A toggle button to change themes.
- **Form Validation:** Adding logic to the contact form.

## 📂 How to View
Simply clone the repository and open `My_portfolio.html` in any modern web browser.
