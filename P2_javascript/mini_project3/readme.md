# 🌤️ Weather Vibe App

A premium, modern, and minimalist responsive Weather Application built with HTML, CSS, and modern JavaScript (ES Modules). The app features a stunning glassmorphism design overlaying a live interactive rain background animation.

## 🚀 Features

* **Dynamic Background**: Uses `@lottiefiles/dotlottie-web` canvas rendering for high-performance background animations.
* **Glassmorphism UI**: Beautiful transparent card interface with real-time blur and glow effects.
* **Modern Typography**: Uses responsive font scaling via CSS `clamp()` for perfect text sizes across all screens.
* **Glowing Loader**: A custom pure CSS modern conic-gradient spinner with dynamic pulse scaling animations during data fetching.
* **Responsive Layout**: Powered by CSS Flexbox (`min-height: 100vh` and `margin-top: auto`), perfectly optimized for Mobile, iPads, and Desktop screens (including F11 full-screen mode).
* **Social Connections**: Clean interactive footer integrated with FontAwesome icons for professional links.

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (ES6+ / Modules)
* **Animations**: DotLottie Web SDK (Canvas-based)
* **Icons**: FontAwesome 6

## 📂 Project Structure

```text
├── index.html          # Main application structure
├── style.css           # Custom responsive styling & glassmorphism layout
├── index.js            # JavaScript handling Lottie animations and API integrations
└── rain-bg.json        # High-performance local animation asset
```

## 💻 Getting Started

### Prerequisites
To handle modern JavaScript ES modules (`type="module"`), you need a local development server. 

### Running Locally
1. Clone or download this project folder.
2. Open the folder in **VS Code**.
3. Install the **Live Server** extension in VS Code.
4. Right-click on `index.html` and select **"Open with Live Server"**.
5. Alternatively, if configured with Node.js, run:
   ```bash
   npm run dev
   ```
